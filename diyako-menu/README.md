# منوی دیاکو — «روزنامهٔ دیاکو»

منوی کافه و رستوران دیاکو به سبک روزنامه‌های قدیمی: کاغذ کاهی، تیترهای درشت، ستون‌بندی، و آرم چرمی دیاکو که به‌صورت برداری (SVG) بازسازی شده است.

| فایل | کاربرد |
|---|---|
| `index.html` | منوی دیجیتال. یک فایلِ مستقل است (فونت‌ها، آرم و تصویرسازی‌ها داخلش هستند) و به هیچ سرور خارجی وصل نمی‌شود. همین یک فایل را روی هاست بگذارید و لینکش را به QR روی میزها بدهید. |
| `diyako-menu-A4.pdf` | منوی کاغذی، دو صفحهٔ A4: «ویژه‌نامهٔ رستوران» و «ویژه‌نامهٔ کافه». |
| `data/menu.json` | همهٔ اسم‌ها و قیمت‌ها. قیمت‌ها به **هزار تومان** است (مثلاً `1700` یعنی ۱٬۷۰۰٬۰۰۰ تومان). |

## عوض کردن قیمت یا اضافه کردن غذا

۱. در `data/menu.json` قیمت را عوض کنید یا یک خط مثل این اضافه کنید:

```json
{ "name": "چلو بختیاری", "price": 1700, "tag": "تازه" }
```

`note` توضیح کوتاه داخل پرانتز است، `tag` برچسب قرمز («تازه») و قیمت دوتایی به شکل `[240, 260]` نوشته می‌شود.

۲. منو را دوباره بسازید (فقط پایتون ۳ لازم است):

```bash
python3 tools/build.py
```

۳. برای PDF چاپی (به Node و Playwright نیاز دارد):

```bash
node tools/make_pdf.js
```

## QR اینستاگرام

جای QR در پایین منوی دیجیتال و پای هر دو صفحهٔ چاپی آماده است. با لینک صفحه یک QR برداری و هم‌رنگ منو بسازید:

```bash
python3 tools/make_qr.py "https://instagram.com/<آیدی>"
```

یا از روی عکس یک QR موجود:

```bash
python3 tools/make_qr.py --from-image qr.png
```

بعد در `data/menu.json` بخش `instagram` را (`handle` و `url`) پر کنید و `tools/build.py` را اجرا کنید.

## ویژگی‌های نسخهٔ دیجیتال

- تاریخ امروز به تقویم شمسی در سرِ روزنامه
- نوار «فوری» برای خبر غذاهای تازه
- فهرست بخش‌ها که بالای صفحه می‌چسبد و بخشِ در حال خواندن را نشان می‌دهد
- جستجو در منو (با «ي» و «ك» عربی هم کار می‌کند)
- «فال قهوه» در صفحهٔ قهوه
- برای گوشی طراحی شده و روی تبلت و کامپیوتر به صفحهٔ روزنامهٔ چندستونه تبدیل می‌شود

## چاپ

PDF در اندازهٔ دقیق A4 و با فونت‌های جاسازی‌شده است. پس‌زمینه سفید است تا روی هر چاپگری بدون حاشیهٔ ناجور چاپ شود؛ برای حس روزنامهٔ قدیمی، روی کاغذ کرم یا شیری (۱۲۰ گرم یا ضخیم‌تر) چاپ کنید.

## ابزارهای یک‌باره

این‌ها فقط برای بازسازی آرم یا فونت‌های چاپی لازم‌اند و خروجی‌شان در مخزن هست:

- `tools/make_logo.py`: آرم چرمی را از روی هندسهٔ اندازه‌گیری‌شده می‌سازد (`assets/logo-*.svg`).
- `tools/make_static_fonts.py`: وزن‌های ثابت فونت برای PDF (`assets/fonts/static`).

این دو به `fonttools`، `brotli`، `uharfbuzz` و `shapely` نیاز دارند.
