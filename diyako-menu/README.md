# منوی دیاکو

منوی رستوران و کافهٔ دیاکو به سبک منوهای چاپی قدیمی، سیاه‌وسفید و پرکنتراست: قاب دوخطی با گل‌وبوته در گوشه‌ها، آرم دیاکو و روبان «رستوران و کافهٔ دیاکو»، فانوس‌های خیابانی دو طرف تیتر «منوی خوشمزه‌ها»، دست اشاره‌گر، کادرهای هاف‌تون، نوار مشکی «ویژه‌های دیاکو» و سه کادر پایین صفحه.

| فایل | کاربرد |
|---|---|
| `index.html` | منوی دیجیتال. یک فایلِ مستقل است (فونت‌ها، آرم و نقش‌ها داخلش هستند) و به هیچ سرور خارجی وصل نمی‌شود. همین یک فایل را روی هاست بگذارید و لینکش را به QR روی میزها بدهید. |
| `diyako-menu-A4.pdf` | منوی کاغذی، دو صفحهٔ A4: صفحهٔ رستوران و صفحهٔ کافه و قلیان. |
| `data/menu.json` | همهٔ اسم‌ها و قیمت‌ها. قیمت‌ها به **هزار تومان** است (مثلاً `1700` یعنی ۱٬۷۰۰٬۰۰۰ تومان). |

## عوض کردن قیمت یا اضافه کردن غذا

۱. در `data/menu.json` قیمت را عوض کنید یا یک خط مثل این اضافه کنید:

```json
{ "name": "چلو بختیاری", "price": 1700, "tag": "تازه" }
```

`note` توضیح کوتاه کنار اسم است، `tag` برچسب مشکی («تازه») و قیمت دوتایی به شکل `[240, 260]` نوشته می‌شود. چهار کادر «ویژه‌های دیاکو» در بخش `specials` همین فایل تعریف شده‌اند.

۲. منو را دوباره بسازید (فقط پایتون ۳ لازم است):

```bash
python3 tools/build.py
```

۳. برای PDF چاپی (به Node و Playwright نیاز دارد):

```bash
node tools/make_pdf.js
```

## QR اینستاگرام

جای QR در کادر «دیاکو در اینستاگرام»، پایین منوی دیجیتال و پای هر دو صفحهٔ چاپی، آماده است. با لینک صفحه یک QR برداری و هم‌رنگ منو بسازید:

```bash
python3 tools/make_qr.py "https://instagram.com/<آیدی>"
```

یا از روی عکس یک QR موجود:

```bash
python3 tools/make_qr.py --from-image qr.png
```

بعد در `data/menu.json` بخش `instagram` را (`handle` و `url`) پر کنید و `tools/build.py` را اجرا کنید.

## ویژگی‌های نسخهٔ دیجیتال

- تاریخ امروز به تقویم شمسی زیر سرِ منو
- فهرست بخش‌ها که بالای صفحه می‌چسبد و بخشِ در حال خواندن را نشان می‌دهد
- جستجو در منو (با «ي» و «ك» عربی هم کار می‌کند)
- برای گوشی طراحی شده و روی تبلت و کامپیوتر به صفحهٔ کامل دوستونه با فانوس‌های بلند تبدیل می‌شود

## چاپ

PDF در اندازهٔ دقیق A4 و با فونت‌های جاسازی‌شده است و فقط با جوهر مشکی چاپ می‌شود. قاب دور صفحه ۴ میلی‌متر با لبهٔ کاغذ فاصله دارد؛ اگر چاپگر حاشیهٔ بیشتری لازم دارد، در تنظیمات چاپ «Fit to page» را بزنید. روی کاغذ کرم یا شیری (۱۲۰ گرم یا ضخیم‌تر) حس منوی قدیمی بیشتر می‌شود.

## ابزارهای یک‌باره

این‌ها فقط برای بازسازی آرم یا فونت‌های چاپی لازم‌اند و خروجی‌شان در مخزن هست:

- `tools/make_logo.py`: آرم را از روی هندسهٔ اندازه‌گیری‌شده از عکس می‌سازد (`assets/logo-*.svg`). نسخهٔ مشکی در منو استفاده شده و نسخهٔ چرمیِ قهوه‌ای (`logo-leather.svg`) برای اینستاگرام یا تابلو آماده است.
- `tools/make_ornaments.py`: گل‌وبوتهٔ گوشه‌ها، فانوس، دست اشاره‌گر و آیکون‌ها (`src/ornaments.svg`). فقط کتابخانهٔ استاندارد پایتون لازم دارد.
- `tools/make_static_fonts.py`: وزن‌های ثابت فونت برای PDF (`assets/fonts/static`).

`make_logo.py` و `make_static_fonts.py` به `fonttools`، `brotli`، `uharfbuzz` و `shapely` نیاز دارند.
